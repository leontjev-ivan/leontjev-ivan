## Что сделал (коммерческие проекты, код у заказчиков закрыт)

**ИИ-агент бронирования для глэмпинг-курорта.** Отвечает гостям в Telegram, WhatsApp, Instagram и MAX, подбирает виллы и цены, сам оформляет бронь с предоплатой 50%, операторы видят все диалоги в общем хабе.
- Разобрали 995 боевых диалогов: провалы нашлись в 70% из них, причины в коде, а не в модели.
- Перестроили: модель понимает запрос, действия выбирает код, каждый ответ режется на утверждения и сверяется с базой цен и дат; при сбое диалог тихо уходит оператору.
- Итог: 410 ходов на боевых переписках без сбоев, расход на модели с $12,5 до $6,5 в месяц.

**Бот поддержки для магазинов франшизы.** Отвечает сотрудникам в рабочих группах по базе знаний из 354 записей, сам решает, отвечать или звать оператора, ответ проверяет отдельная модель. База растёт через подтверждения оператора; стоимость проверки ответа снизили в 4 раза.

**Перевод писем китайским поставщикам.** Конвейер «анализ → глоссарий на 178 терминов → перевод → ревью» и распознавание текста на картинках vision-моделью: 126 писем в месяц, 14,6 с на письмо, около $0,16 в месяц на модели.

**Mini App для врача-эндокринолога.** Переводит продукты в пищевые единицы, распознаёт этикетку по фото за 1,8 с (около $0,0005 за снимок), ведёт дневник пациента и кабинет врача.

**Конструктор ИИ-администраторов для малого бизнеса.** Владелец вносит услуги и цены и получает бота, который отвечает его клиентам; переписки и настройки в личном кабинете.
